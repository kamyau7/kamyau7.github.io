Privacy Policy

Last updated: November 2026

Hong Kong Hiking Guide is a student project website published as a static website using GitHub Pages.

Information we collect

This website does not provide user accounts, comment forms, newsletter subscriptions or online payments. We do not intentionally ask visitors to submit personal information through this site.

Hosting and technical information

The website is hosted by GitHub Pages. The hosting provider may process technical information, such as server logs and IP addresses, as part of delivering and protecting the service. Please refer to GitHub's own privacy statement for details about its services.

External links

Our pages may link to external websites for weather, transport or trail information. Those websites have their own privacy practices, which we do not control.

Changes

This notice may be updated if the website's features or hosting arrangements change.
