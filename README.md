# Hong Kong Hiking Guide

A static website about hiking in Hong Kong, built with HTML and CSS and published through GitHub Pages.

**Live website:** https://kamyau7.github.io/

## Website sections
- Hiking destinations and route guides
- Hiking gear: clothing, shoes, backpacks, food and water
- Hiking tips: safety, preparation, weather and navigation
- About, contact and privacy information

The website contains the 22 published WordPress page topics, with a redesigned static homepage. The original WordPress website remains separate and unchanged.

## Updating the website
Edit the corresponding HTML files in this repository and commit the changes. WordPress edits are not automatically synchronized to this GitHub Pages copy.
